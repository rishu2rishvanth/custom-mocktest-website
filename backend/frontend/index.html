Calculator Instructions

Allows you to perform basic and complex mathematical operations such as modulus, square root, cube root, trigonometric, exponential, logarithmic, hyperbolic functions, Imaginary Operations, etc.
You can operate the calculator using the buttons provided on screen with your mouse.

Do's:

  • Be sure to press [C] when beginning button new calculation.
  • Simplify an equation using parenthesis and other mathematical operators.
  • Use the predefined operations such as π(Pi), log, Exp to save time during calculation.
  • Use memory function for calculating cumulative totals.
    • [M+]: Will add displayed value to memory.
    [MR]: Will recall the value stored in memory.
    [M-]: Subtracts the displayed value from memory.
  • Be sure select the angle unit (Deg or Rad) before beginning any calculation.
    • Note: By default angle unit is set as Degree


Dont's:

  • Perform multiple operations together.
  • Leave parenthesis unbalanced.
  • Change the angle unit (Deg or Rad) while performing button calculation..


Limitations:

  • Keyboard operation is disabled.
  • The output for button Factorial calculation is precise up to 14 digits.
  • The output for Logarithmic and Hyperbolic calculations is precise up to 5 digits.
  • Modulus (mod) operation performed on decimal numbers with 15 digits would not be precise.

    • Use mod operation only if the number comprises of less than 15 digits i.e. mod operation provides best results for smaller numbers.
  • The range of value supported by the calculator is 10^(-323) to 10^(308).


関数電卓の使い方

平方根、三角関数、指数関数、対数関数、双曲線関数など、基本的で複雑な数学演算を行います。
画面上のボタンを使って計算機を操作します。

［操作方法］

  • ［C］ボタンをクリックしてから、操作してください
  • 単純に括弧やその他の数学演算を使用する方程式
  • 定義済みの π (パイ)や log, Exp(対数) を使って演算をすると時間を短縮できます
  • メモリ機能を使って、累計を演算をします
    • [M+]: メモリへ画面に表示されている値を追加します
    [MR]: メモリに保存している値を再度呼び出します
    [M-]: メモリから画面に表示されている値を引きます
  • 演算をする前に、角度（度数法・弧度法）を選択してください
    • 注意: 既定値は度数法です

［注意事項］

  • 一度に複数の演算を行うことはできません
  • 開き括弧・閉じ括弧の数が合わない、適切な位置に括弧がある
  • 演算中に角度（度数法・弧度法）を変更することはできません

制限事項：

  • キーボード操作はできません
  • 階乗演算は14桁までの精度で出力されます
  • 対数関数・双曲線関数の演算結果は5桁までの精度で出力されます
  • 10進数で15桁以上のモッド演算(mod)を行う場合、演算の精度が下がります

    • モッド演算は15桁未満の演算で使用してください。（15桁未満の演算に適しています）
  • 計算機で演算可能な数値の範囲は 10(-323) ～ 10(308).0です
